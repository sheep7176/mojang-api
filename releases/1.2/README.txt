=========================================
Minecraft UUID & 皮肤查询工具 v1.2
=========================================

【环境要求】
1. 请确保您的电脑已安装 Python 3.6 或更高版本。
2. 本项目依赖 requests 库，如果没有请先安装 requests 库！

【安装依赖】
打开 PowerShell 窗口/命令行。
输入以下命令并回车安装依赖：
pip install requests

【运行程序】
依赖安装完成后，在解压后的路径下输入以下命令并回车：
python main.py
(如果提示找不到 python，请尝试输入 py main.py)

【注意事项】
- 下载的图片会保存在当前文件夹中。
- 如果提示“找不到语言文件”，请确保 language 文件夹和 main.py 在同一个目录。
