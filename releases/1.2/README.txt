=========================================
Minecraft UUID & 皮肤查询工具 v1.2
=========================================

【环境要求】
请确保您的电脑已安装 Python 3.6 或更高版本。
如果您未安装 Python，直接双击运行程序时，程序也会尝试引导您安装。
【一键运行】
如果您不想折腾环境配置，请直接双击运行解压后的：
 "run.exe"
（它全自动检测并安装缺失的依赖，源代码也在同一个 GitHub 仓库上，名为 run.cpp）
如果您遇到问题，也可以从GitHub上下载下来使用 C++ 编译器手动编译：
g++ run.cpp -o run.exe -static
-----------------------------------------
【手动运行教程】
如果您想自己配置环境，请按照以下步骤操作：
1. 安装依赖：
在当前文件夹空白处，按住 Shift 键 + 鼠标右键，选择“在此处打开 PowerShell/命令行”。
输入以下命令并回车（这里加了国内镜像源加速）：
pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple
2. 运行程序：
依赖安装完成后，输入以下命令并回车：
python main.py
(如果提示找不到 python，请尝试输入 py main.py)
-----------------------------------------
【注意事项】
- 下载的皮肤/披风图片会保存在当前文件夹中。
- 如果提示“找不到语言文件”，请务必确保 language 文件夹和 main.py 在同一个目录下。
- 程序支持简体中文和英文，启动时可自由选择。
